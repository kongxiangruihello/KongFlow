# KongFlow 0.32 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

- 成对标点不再改变中英文状态：中文状态下用 Shift 输入（ “ 《 ｛ 等成对标点后仍是中文，英文状态同样保持英文。单按 Shift 切换中英文不受影响。
- 候选超过每页数量时折叠显示：候选窗口下方显示「更多 ▾」，点击或按 Tab 展开，展开后显示「收起 ▴」。底栏与候选框同色，不再是透明区域里的小箭头。
- 继承 0.31 的输入诊断、简拼自检与切换结果核验。

安装：双击 KongFlow-0.32.dmg，运行其中的「安装KongFlow.pkg」。安装后保存工作并注销、重新登录，选择 KongFlow 中文模式，保存并应用配置。

建议试打：中文状态输入 Shift+9、Shift+'、Shift+,，确认仍为中文；输入 zgd，确认候选下方出现「更多 ▾」并可展开、收起。

此包为本地签名测试版，未使用 Developer ID 签名或 Apple 公证。
