# KongFlow 0.34 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

- 候选窗口重写：每个候选先单独测量尺寸，再统一算出整个窗口的布局，窗口大小正好等于内容，背景、高亮、文字和底栏在同一次绘制中完成。去掉了原来的滚动区、文字排版视图和按局部区域生成的轮廓，展开、收起或候选数量变化时不会再沿用上一次的尺寸，避免显示不完整。
- 每个候选是一个整体，换行只发生在候选之间，不会把一个词拆到两行。
- 内容放不下时自动加宽窗口（屏幕宽度的三分之一 → 0.6 → 0.95），不再在窗口里滚动。
- 新图标「光标 K」（应用图标与菜单栏图标）。
- 竖排文字（text_orientation: vertical）不再支持；KongFlow 一直使用横排。

安装：双击 KongFlow-0.34.dmg，运行「安装KongFlow.pkg」，注销并重新登录，在设置中保存并应用配置。

此包为本地签名测试版，未使用 Developer ID 签名或 Apple 公证。
