# KongFlow 0.35 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

本版新增十项功能，均可在「设置 → 输入习惯 → 学术写作」等处单独开关，保存并应用后生效。

1. 繁体输出：Control＋Shift＋F 或输入法菜单「繁体输出」切换；设置里可设为默认繁体。按 OpenCC 简转繁（s2t）转换。
2. 生僻字与部件拆字：收入雾凇 41448 大字表（排在常用字之后）；输入 u＋各部件拼音拆字查字，如 ushanfeng →「岚」。
3. 学术标点：引号可选弯引号“”‘’或直角引号「」『』；书名号《》内再输入 < 自动成〈〉。原有的 `→·、\→、、^→……、_→—— 不变。
4. 年号纪年互查：i＋年号拼音（全拼或首字母）＋年数，如 ikx20 →「康熙二十年（1681）」，附朝代、君主、干支；i＋公元年，如 i1681，列出当年各政权年号；公元前加 q，如 iq140。收录 508 个年号（自汉武帝建元起，至宣统），依据万国鼎《中国历史纪年表》，经 ytliu0/ChineseCalendar 整理。十六国大部分、十国、西夏等政权尚未收录。
5. 四书原文速输：v＋句子或分句开头的拼音首字母，如 vxesx →「学而时习之，不亦说乎？」，候选旁标出处（论语·学而 1.1）。《论语》20 篇 512 章，与杨伯峻《论语译注》分章一致；文本来自 chinese-poetry 开源数据。繁体模式下输出繁体。
6. 以词定字：有候选时按 [ 上屏首字、] 上屏末字。翻页键设为 [ ] 时自动停用。
7. 带调拼音：/＋数字标调拼音，如 /lun2yu3 → lúnyǔ，另给分写与首字母大写；v 表示 ü，自动加隔音符号（nǚ'ér）。
8. 专业词库：设置 → 你的词库 → 专业词库，选择讲稿所在文件夹（.txt、.md、.docx），本机找出词库中没有的常用词，核对拼音后勾选加入个人词语。
9. 候选疏密：设置 → 候选外观 → 紧凑／标准／宽松。
10. 本地输入统计：只记录每天上屏字数、汉字数和次数，不记录内容；设置里查看或关闭。

注意：输入 i、v、u、/ 开头时进入对应功能，期间数字是输入的一部分，不能用数字键选候选，请用空格或鼠标。
