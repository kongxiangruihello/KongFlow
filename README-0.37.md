# KongFlow 0.37 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

1. 菜单精简：输入法菜单去掉「日志」和「在线文档」（Rime Wiki）两项。
2. 输入统计进菜单：「开发者」下方新增「输入统计：今日 N 字」，子菜单列出今日（汉字数、上屏次数）、近 7 日、近 30 日与累计字数；点任一行打开设置。统计只记字数，不记内容；在设置里关闭后显示「输入统计：已关闭」。
3. 新图标：按新设计稿（蓝色圆角底、带速度线的 K、键盘）制作应用图标；菜单栏图标改为同款单色 K 加速度线。

保存并应用后生效。此包为本地签名测试版，未使用 Developer ID 签名或 Apple 公证。
