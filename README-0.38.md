## 换电脑一键迁移（iCloud）

位置：设置 → 备份与恢复 → 最上方「换电脑一键迁移（iCloud）」。

**旧电脑**
- 默认每天自动备份一次：键盘空闲 10 分钟后，输入法暂停约 1–2 秒，把完整备份写入 iCloud Drive / KongIME / Migration / <这台 Mac>。可在同一处关闭。
- 也可随时点「立即备份到 iCloud」。换机前建议手动备份一次，确保包含最新内容。
- 自动备份每台 Mac 保留最近 10 份；手动备份不自动删除。本机还没有任何个人数据时不做自动备份，避免空白备份。

**新电脑**
1. 两台 Mac 登录同一 Apple 账号并开启 iCloud Drive。
2. 安装 KongFlow，在「系统设置 › 键盘 › 输入法」添加 KongFlow 并切换一次。
3. 打开 KongFlow 设置：首页会提示「在 iCloud 发现 KongFlow 备份」，点「一键恢复」（或到「备份与恢复」，在对应 Mac 一行点「一键恢复」）。
4. 恢复完成后自动应用到输入法，无需再点「保存并应用」。

**包含**：输入习惯与外观等全部设置、导入词库、个人词语与置顶、短语、候选屏蔽与快捷排序、模糊音、应用语言偏好、场景与回收站、字号表、学习词频、我的典籍、本地输入统计（按天合并，取较大值）。
**不包含**：程序本身、各应用临时的中英文状态。

恢复前会保留本机现状：配置与学习词频可在「完整迁移备份」中「预览并回退完整迁移」；原「我的典籍」另存为 classics_user.before-migration.json。备份文件未加密，存放在你的 iCloud Drive。

另：字号表现在也纳入「统一备份」「iCloud 备份」与「完整迁移备份」（此前遗漏）。

此包为本地签名测试版，未使用 Developer ID 签名或 Apple 公证。
