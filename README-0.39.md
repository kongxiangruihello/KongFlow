# KongFlow 0.39 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

## 设置重新编排

左侧六个页面，各管一件事：

| 页面 | 内容 |
|---|---|
| 输入 | 试打；候选与翻页（含快捷键）；拼写与推荐（简拼、拼音显示、学习推荐、模糊音）；中英文与标点（含引号样式）；候选外观；按应用设置 |
| 学术写作 | 繁体；生僻字与拆字；年号、纪日、典籍与注音（含引文出处）；我的典籍；字号表 |
| 词库 | 你的词库、场景、新建与导入、专业词库、导入记录；有待处理的特殊词条时从这里进入 |
| 我的词语 | 个人词语、常用短语、快捷排序；修改记录与回收站 |
| 备份与恢复 | 换电脑一键迁移（iCloud） |
| 关于与诊断 | 输入法状态、版本与更新、一键诊断与简拼自检、输入统计、旧版数据迁移与导出 |

**去掉的重复**
- 保存：原先有「自动保存配置」「保存配置」「保存并应用」「保存外观」「保存偏好」「保存并应用模糊音」「保存并应用后试打」七处。现在所有设置改动自动保存，只保留右上角「应用到输入法」。
- 试打：原先三处（输入测试区、输入习惯里的试打行、安装页的真实输入测试），现只保留「输入 › 试打」。
- 诊断与版本：原先散在「设置」首页和「安装与备份」两处，现集中到「关于与诊断」。
- 「安装与备份」与「备份与恢复」名称重叠：前者改为「关于与诊断」，旧的手动备份与恢复入口收起，日常备份统一用「备份与恢复」。
- 「词库／个性化」页内二级切换取消，改为独立页面；「候选样式示意」演示图移除（外观页已有实时示意）。
- 各处说明里重复的「保存并应用后生效」删去，页首统一说明一次。

**其他**
- 引号样式从「学术写作」移到「输入 › 中英文与标点」。
- 设置搜索按新位置跳转，新增繁体、字号表、典籍、输入统计、回收站等搜索项。
- 菜单「设置…」打开「输入」页；菜单里「输入统计」打开「关于与诊断」。
- 修复：全新安装（还没有任何配置时）打开设置，字号表接口报错。
