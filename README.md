# KongFlow 0.37 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

本版：菜单精简（去掉「日志」「在线文档」），输入统计显示在「开发者」下方；新图标。详见 [0.37 说明](README-0.37.md)。

上一版：典籍扩充与「我的典籍」、引文带出处、农历与干支纪日、年号补充、繁体细分、字号互查。详见 [0.36 说明](README-0.36.md)。

上一版：新增繁体输出、生僻字与拆字、学术标点、年号纪年互查、四书速输、以词定字、带调拼音、专业词库、候选疏密、本地输入统计。详见 [0.35 说明](README-0.35.md)。

上一版：候选窗口重写，窗口大小由内容直接算出，修复展开／收起后显示不完整；新图标「光标 K」。详见 [0.34 说明](README-0.34.md)。

上一版：折叠时显示数量与展开后数量可设置，展开行可用 Shift＋数字选择；新增 GitHub Actions 自动构建 DMG。详见 [0.33 说明](README-0.33.md)、[0.32 说明](README-0.32.md)。

原 KongIME 输入法更名为 KongFlow。菜单栏保留单色 K，方案名称 KongFlow 全拼。保留原应用标识、个人数据目录与备份兼容性，以便原地升级；与其他同名应用不共用应用标识。

- 中文／英文切换提示使用完整中文文字，输入法菜单显示当前语言模式。
- 安装与备份页增加当前应用输入诊断：输入源、简拼开关、配置应用状态、运行版本、最近输入应用及语言模式。无法检测时明确显示待确认。不记录输入文字；最近应用状态不等于当前前台应用状态。
- 继承 0.29 简拼引擎自检及 0.30 切换结果核验，切换失败不再提示成功。

安装后保存工作并注销、重新登录，选择 KongFlow 中文模式，保存并应用配置。先运行简拼自检，再用物理键盘在备忘录、Word、Chrome、微信草稿中测试 nihao、nh、zg、ni'h。微信不发送测试内容。

四应用实测尚未完成，不能以引擎检查代替兼容性验收。此包为本地签名测试版。
