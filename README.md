# KongFlow 0.32 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

本版：成对标点不再改变中英文状态；候选超出每页数量时显示「更多 ▾」折叠入口。详见 [0.32 说明](README-0.32.md)。

原 KongIME 输入法更名为 KongFlow。菜单栏保留单色 K，方案名称 KongFlow 全拼。保留原应用标识、个人数据目录与备份兼容性，以便原地升级；与其他同名应用不共用应用标识。

- 中文／英文切换提示使用完整中文文字，输入法菜单显示当前语言模式。
- 安装与备份页增加当前应用输入诊断：输入源、简拼开关、配置应用状态、运行版本、最近输入应用及语言模式。无法检测时明确显示待确认。不记录输入文字；最近应用状态不等于当前前台应用状态。
- 继承 0.29 简拼引擎自检及 0.30 切换结果核验，切换失败不再提示成功。

安装后保存工作并注销、重新登录，选择 KongFlow 中文模式，保存并应用配置。先运行简拼自检，再用物理键盘在备忘录、Word、Chrome、微信草稿中测试 nihao、nh、zg、ni'h。微信不发送测试内容。

四应用实测尚未完成，不能以引擎检查代替兼容性验收。此包为本地签名测试版。
