# KongIME 0.27

KongIME ---- 自由输入，专注表达。

开发者：孔祥瑞。Apple Silicon Mac，macOS 13 及以上。

## 本版更新

1. 候选屏蔽可选范围：候选窗口右键选择“仅在当前拼音下隐藏”或“所有拼音下隐藏”。例如仅在 nh 下隐藏“你好”，nihao 和 ni'h 仍可显示它。当前拼音按实际输入字母精确匹配；不会删除词库原词。
2. 在“我的词语 → 快捷排序”中查看、筛选、切换屏蔽范围或取消屏蔽。范围切换需要确认，最近修改可撤销。旧版屏蔽保持所有拼音生效。
3. 应用候选间距：在“设置 → 个性化 → 应用输入兼容性”选择应用，可设为 8、12、18、24 或跟随全局。独立间距与应用的中英文和标点规则分别保存，不会相互覆盖。
4. 兼容检查：全拼、简拼、混输、候选过滤与多屏避让已通过自动检查。微信、Word、Chrome、备忘录的实际输入检查需要安装本版后进行，见 VALIDATION-0.27.md，不把自动检查当成第三方应用实测。

## 安装与使用

解压后打开“安装KongIME.pkg”。安装完保存工作，再注销并重新登录 macOS，确保正在运行的是 0.27.0。在 KongIME 菜单打开“设置”，确认设置、已安装、正在运行三个版本一致，点击“保存并应用”。

菜单栏显示 K，方案为 KongIME 全拼。升级保留既有词库、短语、候选偏好和学习数据。建议先保留个人备份。

应用间距保存后需要应用配置。快捷屏蔽在新版规则加载后，下次输入生效，无需每次重新部署。切换到没有独立间距的应用时恢复全局间距。

## 备份兼容

本版个人备份包含按拼音屏蔽和应用间距。完整迁移要求已安装的客户端与设置版本一致；旧版客户端不识别新增的按拼音屏蔽，含这类规则的备份请使用 0.27 或更新版本恢复。

## 验证范围

本版为测试版，使用本地临时签名，尚无 Developer ID 签名和 Apple 公证。跨应用实测与两台物理 Mac 的完整迁移尚待验证，iCloud 自动备份仍保持关闭。
