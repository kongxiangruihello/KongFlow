# KongIME 0.28

KongIME ---- 自由输入，专注表达。

开发者：孔祥瑞。适用于 Apple Silicon Mac、macOS 13 及以上。

## 本版更新

1. 候选操作立即撤销：置顶、取消置顶、降权和屏蔽后，屏幕右上角显示具体操作与“撤销”按钮，提示保留 8 秒。也可通过 KongIME 菜单的“撤销上次候选调整”操作。撤销不占用编辑器的 Command-Z，不删除原词库。若设置窗口或其他操作已经产生更新的调整，旧撤销会拒绝执行，请在最近修改中按顺序撤销。
2. 临时暂停词频学习：菜单增加“暂停词频学习”，可暂停直到手动恢复，或暂停到本次输入法退出。暂停仍使用已有学习词频排序，但不增加本次选词的学习记录。切换应用不会解除暂停。“本次输入法退出”指输入法进程退出或注销，不是关闭某个编辑器。恢复学习遵循设置中的学习总开关，不会强行开启已关闭的推荐。
3. 兼容性检查：真实引擎已验证全拼、简拼、混输和整句在暂停时正常上屏且学习数据不变，恢复后继续学习。原生候选窗口在本机一块物理屏幕上通过 15 项长词与屏幕边缘检查；四个常用应用实测仍需安装本版后完成。

## 升级与使用

先备份个人数据，解压并打开“安装KongIME.pkg”。完成安装后保存其他工作，注销并重新登录 macOS，确认设置、已安装、正在运行均为 0.28.0，点击“保存并应用”。旧部署缺少暂停学习规则时，客户端会提示先应用新版配置，不会报告虚假的暂停成功。

切换学习状态前，请完成或取消正在输入的拼音。持续暂停偏好只保存在本机；本次会话暂停只保存在内存，不写入个人词库备份。这个功能仅控制 KongIME 词频学习，不代表编辑器或其他应用不会保存文本。

0.27 的按拼音屏蔽和按应用候选间距继续保留。菜单栏显示 K，方案名称为 KongIME 全拼。

本版是测试版，使用本地临时签名，尚无 Developer ID 签名和 Apple 公证。微信、Word、Chrome、备忘录实测及两台 Mac 的 iCloud 恢复仍待完成。详细记录见 VALIDATION-0.28.md，iCloud 自动备份继续保持关闭。
