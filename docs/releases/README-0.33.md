# KongFlow 0.33 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

- 折叠时显示数量可设置：设置 → 输入习惯 →「折叠时显示」，可选整页、3、5、7 个。其余候选收进「更多 ▾」，数字键仍可选择整页候选；用方向键移到折叠部分时会自动显示到高亮位置。
- 展开后显示数量可设置：「展开后共显示」可选自动（至少 9 个或两页）、12、18、27、36 个。
- 展开后超出一页的候选标为 ⇧1…⇧9，按 Shift＋数字直接选择；更多的仍可用鼠标点选。
- 展开／收起时不再先隐藏候选窗口，减少闪烁；移除 0.32 排查用的尺寸日志。
- 新图标「光标 K」：K 的竖笔是文字光标，下方一道波浪线表示流畅输入；蓝色底与 KongFetch 等 Kong 系列应用统一。菜单栏输入法图标为同一个 K 的单色版。
- 新增 GitHub Actions 自动构建：推送到 main 或手动运行后，在 macOS 云端编译、测试并生成 DMG。

安装：双击 KongFlow-0.33.dmg，运行「安装KongFlow.pkg」，然后注销并重新登录，在设置中保存并应用配置。

此包为本地签名测试版，未使用 Developer ID 签名或 Apple 公证。
