# KongFlow 0.36 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

1. 典籍扩充：v 速输在四书之外，新收《诗经》（305 篇）、《楚辞》、唐诗三百首和蒙学（三字经、千字文、百家姓、弟子规、增广贤文），文本来自 chinese-poetry 开源数据（MIT）。
2. 我的典籍：设置 → 学术写作 → 我的典籍，导入自己的 .txt、.md、.docx（一个文件一部书，# 开头的行为篇名），同样用 v＋句首拼音首字母速输。
3. 引文带出处：首选可连出处上屏，如「学而时习之，不亦说乎？（《论语·学而》）」；可选括注、破折号或只上屏原文，另一种形式在第二候选。
4. 农历与干支纪日：i＋公历年月日（8 位），如 i16810315 →「康熙二十年正月廿六」，并给出干支纪年与日干支；公元前加 q。1582 年 10 月 15 日以前按儒略历理解（史学惯例）。农历月表取自刘玉棠（Yuk Tung Liu）计算的历代历表（ytliu0/ChineseCalendar，GPL-3.0），范围公元前 221 年至公元 2100 年。
5. 年号补充：据「明正朔」（MIT）补入 19 个年号（十六国诸政权、南唐、隋恭帝皇泰、武周久视），候选注「据明正朔」；该来源本身尚不完整，十六国、十国、西夏等仍有缺漏。后燕光始按通行纪年订为 401–406 年（来源作 7 年）。
6. 繁体细分：通用繁体、台湾用字、台湾用字与用词、香港用字（OpenCC）。
7. 字号互查：设置里粘贴字号表（本名、类别、字号，Tab 分隔）。之后输入字号全拼，首选之后列出本名（yangming → 王守仁）；输入本名全拼，列出其字号。拼音按常用读音自动标注，多音字可在第四列自填。

保存并应用后生效。此包为本地签名测试版，未使用 Developer ID 签名或 Apple 公证。
