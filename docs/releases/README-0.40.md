# KongFlow 0.40 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

## 按键响应提速

**原因**：0.35 起加入的典籍速输把约 2.9 万行原文（0.36 扩充后）在输入法启动时拆成 2.9 万个 Lua 表常驻内存。Lua 的垃圾回收器每次运行都要遍历这些表，而每次按键都会触发 Lua 组件，于是**所有按键**——即使从不用 v 速输——都多花约 20 毫秒。

**改法**：
- 典籍原文改为整个文件读成一个字符串，首次输入 v 时才读取，查找时在字符串里按「换行＋首字母」定位。
- 字号表同样改为字符串查找。
- 农历月表（2.9 万个月）打包成二进制字符串（每月 8 字节），用二分查找读取。
- 候选结果与改动前逐字一致（典籍、年号、农历日期、字号互查共 15 组输入对照）。

**实测**（Linux，librime 1.10 + librime-lua，同一套方案与词库，每次按键含读取候选；Mac 上绝对值不同，比例相近）：

| 输入 | 改动前 | 改动后 |
|---|---|---|
| nihao | 22.8 毫秒/键 | 0.8 毫秒/键 |
| womenyiqiqushangxue | 25.3 | 1.2 |
| nh（简拼） | 23.7 | 0.7 |
| vxesx（典籍） | 27.1 | 1.2 |
| i16810315（农历） | — | 0.8 |

用过典籍、农历、字号功能之后再打普通拼音，速度不受影响。
