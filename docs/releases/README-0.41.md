# KongFlow 0.41 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

## 在线更新

设置 → 关于与诊断 → 版本更新：

1. 点「检查更新」。发现新版本时，旁边出现「下载并安装 0.xx（约 xx MB）」。
2. 点它并确认。设置会下载安装包、核对无误后自动打开安装程序。
3. 按安装程序的提示完成安装（需要管理员授权）。安装后保存工作，注销并重新登录。

个人词库、短语、配置与学习记录不受影响；安装程序仍会先把旧客户端复制到本机备份目录。

**它做了什么、没做什么**

- 只在你点按钮时联网，不在后台自动检查，也不上传词库或输入内容。
- 安装包只从本项目的 GitHub 发布页下载；下载途中若被转到 GitHub 以外的站点，立即停止。
- 下载完成后核对文件大小与 GitHub 记录的 SHA-256，不一致就删除并报错，不会打开。
- 如果发布页只有 zip、没有 DMG，或 GitHub 没有给出校验值，则不提供按钮，仍可点链接到发布页手动下载。
- 下载的安装包保存在「~/Library/Application Support/KongIME/manager/updates」，只保留最近一份。
- 访问 GitHub 较慢或不通时会提示重试；系统设置里配置了网络代理时，下载会使用它。

同时修复：此前「检查更新」只认 zip 安装包，而 0.39 起发布页只提供 DMG，因此检查不到新版本。现在两种都认。

## 内部整理（使用上无变化）

- 版本号只写在 `version.py` 一处。此前学习词频迁移靠一份逐个列出版本号的名单判断是否可用，发新版漏加一项就会失效；现改为「不低于 0.16」。
- 输入法等待学习词频维护脚本时增加了时限（请求 120 秒，恢复与每日自动备份 60 秒），脚本卡住不会再让输入法无限期停住。
- 设置程序的本机接口由两段长条件判断改为路由表；两份重复的备份校验合并为一份；程序自身出错时返回「内部错误」并留下出错位置，不再与填写错误混在一起。
- 全部 Python 与网页代码统一排版（ruff、prettier），配置见 `pyproject.toml` 与 `.prettierrc.json`。
- 各版本说明与验证记录移到 `docs/releases/`。

此包为本地签名测试版，未使用 Developer ID 签名或 Apple 公证。在线更新核对的是「与发布页上的文件一致」，不能替代公证。
