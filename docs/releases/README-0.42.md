# KongFlow 0.42 测试版

KongFlow ---- 自由输入，专注表达。
开发者：孔祥瑞。

## 日常工具

位置：设置 → 输入 → 日常工具。四项默认开启，可逐项关闭；升级后点一次「应用到输入法」生效。

1. **英文单词候选**：中文状态下直接打 hello、github、iphone，候选里出现 hello、GitHub、iPhone（大小写按词库）。也收了「X光」「T恤」这类中英混合词。
   - 同样的字母能拼出中文时，中文在前：women → 我们、women。
   - 容易挡住简拼的短单词（as、my、bat 等约 300 个）固定排在第二位之后：my → 没有、my。
   - i、v 开头时先列年号与典籍，英文排在其后：is → 始元…、is；没有对应年号或典籍时直接是英文：internet、video。
   - u 开头仍只用于拆字，不出英文。大写开头的输入照旧直接上屏英文。
2. **错音错字提示**：按错误的读音或写法打出常见词时，在候选旁标出正确的。只提示，不改变候选顺序。
   - 错音：geiyu →「给予 jǐ yǔ」；打 hundun 时，候选「馄饨」旁标 hún tun；打 zhujiao 时，候选「主角」旁标 zhǔ jué。
   - 错字：annai →「按耐 按捺(nà)」。
   - 关闭「显示候选词拼音」时，候选旁平时为空，只在有提示时显示。
3. **数字与金额大写**：大写 R＋数字。R1234.5 →「一千二百三十四点五」「壹仟贰佰叁拾肆点伍」「一千二百三十四元五角」「壹仟贰佰叁拾肆元伍角」。
4. **Unicode 码位输入**：大写 U＋十六进制码位。U62fc →「拼」，其后列出以该码位开头的后续字符。适合按码位输入在字表里查到的生僻字、异体字。

这四项用的是雾凇拼音自带的组件与词库（melt_eng 英文词库、others 容错词表、corrector / number_translator / unicode 脚本），此前已随安装包分发，只是没有接入；安装包体积不变，全部在本机运行。

**需要知道的变化**

- 一些原先凑出生僻组合的字母串，首选变成了英文：the（原「他和」）、app（原「挨批评」）、ok（原「偶看」）、web、bug、doc 等。400 多个拼音音节与常用简拼（bj、sh、zg、nh、mt…）的首选经逐个对照没有变化。不习惯可关闭「英文单词候选」。
- 中文状态下输入 R2、U2 这类「R＋数字」「U＋十六进制字符」时会出现大写数字或 Unicode 候选，按回车仍上屏原样字母。不需要可关闭对应两项。
- 开启错音错字提示后，词库多收约 900 条容错词（如「按耐」），它们会作为候选出现并带提示。
- 按键处理时间：实测每键由约 0.5 毫秒变为约 1 毫秒（Linux，librime 1.10，同一套词库；0.40 提速前约为 23 毫秒）。

**同时修复**：部署后的自检现在带上雾凇的脚本与英文词库再检查。否则新接入的组件在自检环境里缺文件，会把正常的部署误报为失败。
