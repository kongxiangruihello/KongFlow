开发者：孔祥瑞。

## 菜单里的版本更新

点菜单栏的 KongFlow 图标，下拉菜单里：

1. **检查更新…**：紧跟在「设置…」下面。点它会打开设置的「关于与诊断 › 版本更新」并立即检查，不用再自己找位置。
2. **有新版本 0.xx · 点此更新…**：上次检查发现了比当前更新的版本、而你还没有安装时，这一行出现在菜单最上方。点它同样打开版本更新，再点「下载并安装」即可。装到该版本后这一行自动消失。

仍然只在你点「检查更新」时联网，不在后台自动检查；菜单最上方的提示来自上一次检查的结果。

## 新的菜单栏图标

菜单栏图标换成「实心圆角方块、镂空 K」，与系统自带输入法图标（拼、A）同一种形制。原来的 K 加两道速度线在菜单栏的小尺寸下容易糊成一团。浅色、深色菜单栏下由系统自动反色。应用图标不变。

菜单栏图标由系统缓存，安装后需要注销并重新登录才会换成新的。
